# Changelog

## 0.1.0 — Unreleased

Development version with the contract in `docs/contract.md`.

- Immutable bounded BitGrid with detached byte and BitSet boundaries.
- Union-find foreground labeling with deterministic row-major labels, component areas and half-open bounding boxes.
- Inclusive area retention and dual-connectivity hole filling with virtual exterior background.
- Exact checked-integer separable squared Euclidean distance to background, including the exterior frame.
- JDK-only PNG adapter with compressed-size, dimensions, scratch and grayscale-model preflight; raw sample thresholding and explicit alpha rejection.
- Self-contained independent BFS and brute-force oracles, exhaustive 3×3 masks, ownership and adversarial IO/resource tests.
- Synthetic temporary PNG demo with textual and JSON numerical reports.
- Plain Java 21 scripts, strict warnings, read-only CI and English/Portuguese documentation.

No deployment, performance, certification or production-readiness claims are attached to this development version.
